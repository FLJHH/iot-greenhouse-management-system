# 基于物联网的农业大棚生产管理系统

本项目是一套面向农业大棚的物联网生产管理系统，包含 Web 上位机、3 套 STM32 下位机工程，以及毕业设计论文、答辩材料和演示视频。系统用于采集大棚环境数据、展示实时状态，并通过物联网链路实现设备监测与控制。

## 主要功能

- 环境数据采集与实时监控
- 传感器历史记录与动态曲线展示
- 设备远程控制与状态管理
- 用户登录、注册与个人信息管理
- RFID、消息、视频等扩展功能
- 数据导出为 Excel

## 技术栈

- 前端：HTML5、CSS3、JavaScript、Vue.js、Element UI、ECharts
- 嵌入式：STM32、C、Keil MDK
- 通信与外设：MQTT/WebSocket、串口、DHT11、OLED 等

## 快速开始

### Web 上位机

1. 进入 `代码/上位机代码`。
2. 使用现代浏览器打开 `index.html`。
3. 如需访问联网功能，请先检查 `js/project_config.js` 中的服务地址、MQTT 地址和项目配置，确保对应服务仍可用。

> `说明.txt` 中保留了原始演示账号信息。公开部署或二次开发前，请务必替换演示口令及 MQTT 凭据，避免继续使用默认密码。

### STM32 下位机

1. 使用 Keil MDK 打开各工程 `USER/ADC.uvproj`。
2. 按实际开发板修改芯片型号、引脚和外设参数。
3. 编译后通过 ST-Link 等工具烧录到对应 STM32 节点。
4. 根据现场网络和传感器接线配置网关与上位机通信。

## 注意事项

- 本仓库包含毕业设计原始工程，部分第三方前端库以源码形式随项目保存。
- 下位机工程中的编译中间文件已通过 `.gitignore` 排除，生成的固件文件可按需重新编译。
- 项目内配置的远程服务属于原始开发环境，未来可能失效；建议二次开发时改为自有后端和消息服务。
- 当前项目未声明开源许可证；未经作者许可，不代表允许将代码用于商业分发。
